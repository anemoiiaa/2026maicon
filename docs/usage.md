# 사용 가이드

현재 파일은 개발 골격입니다. 실행 명령과 패키지 버전은 실제 구현·검증 후 추가합니다.

## 구현 순서

1. 정형 데이터 읽기 → 분할 → 전처리 → 학습 → 평가 → CSV 저장을 먼저 연결합니다.
2. 제출 형식과 데이터 누수 검사를 완성합니다.
3. 텍스트·센서·이미지 경로를 순서대로 확장합니다.
4. 제공 Notebook으로 코드를 이식하고 새 커널에서 전체 실행합니다.

## 설정 작성

configs/tabular.example.json을 별도 이름으로 복사합니다. 경로·정답 열·ID·공식 지표·예측 형식·제출 열을 실제 연습 데이터 기준으로 수정합니다. 예시의 accuracy와 stratified는 공식 지표나 고정 분할 정책이 아닙니다.

## 한 문제의 작업 순서

1. 입력과 제출 예시를 확인합니다.
2. 시간·그룹 구조에 맞게 검증 분할을 정합니다.
3. 학습 데이터로만 전처리를 학습합니다.
4. 작은 표본으로 전체 흐름을 확인합니다.
5. 동일 분할·지표에서 한 요소씩 바꿔 비교합니다.
6. 선택한 설정으로 전체 학습 데이터를 재학습하고 테스트를 예측합니다.
7. 원본 ID 순서, 행 수, 열 이름, 결측, 클래스/확률 형식을 검사합니다.
8. Notebook의 코드와 실행 결과를 저장하고 최종 제출을 별도로 확인합니다.

## 문서 사용

모듈 추가 시 docs/templates/module.md를 복사하고, 실험마다 experiment.md를 복사합니다. Notion의 같은 이름 템플릿도 복제하여 사용할 수 있습니다. GitHub 커밋을 기록하여 문서와 코드 버전을 연결합니다.
