# 모듈 설계

| 모듈 | 책임 | 입출력 계약 |
|---|---|---|
| config | 경로·목표 열·지표·시드·시간 예산 | 설정 → 검증된 설정 |
| data | 파일 읽기·형태·결측·ID 검사 | 경로 → 데이터와 원본 ID |
| split | 무작위·그룹·시간 분리 | 데이터·분할 정책 → 학습/검증 인덱스 |
| features | 학습 전처리 적합·검증/테스트 변환 | 학습 데이터 → 전처리 객체; 데이터 → 특징 |
| models | 모델 생성·학습·예측 | 특징·정답 → 모델; 특징 → 클래스 또는 확률 |
| evaluate | 공식 지표와 오류 분석 | 정답·예측·지표 → 점수 |
| submission | 열·행·ID 순서·결측 검사와 CSV 저장 | 예측·원본 ID·제출 규격 → 검증된 CSV |
| runner | 전체 실행 순서·시간 기록 | 설정 → 실행 결과·점수·소요 시간 |

## 유형별 확장

- 정형: 결측·범주형 처리와 선형/트리 모델
- 센서: 구간 통계와 변화량, 그룹/시간 누수 검사
- 텍스트: TF-IDF와 선형 분류
- 이미지: 분류/객체 탐지 별도 경로, CPU 시간·가중치 허용 여부 확인

유형별 모듈은 아직 구현하지 않았습니다. 예선 3문항이 위 유형별로 하나씩 나온다는 의미는 아닙니다.

## 공통 불변 조건

학습 데이터로만 전처리를 적합합니다. ID를 특징에서 제외하고 예측 후 원래 순서를 복구합니다. 클래스 번호와 확률을 구분하고 클래스 순서를 명시합니다. 최종 Notebook은 개인 로컬 모듈 없이도 필요한 구현이 포함되어야 합니다.
